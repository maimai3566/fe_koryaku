# FE万紫千紅 - 主人公別スカウト・加入条件まとめ

『ファイアーエムブレム 万紫千紅（Fortune's Weave）』における、各主人公（カイ、ディートリヒ、セオドラ、レダ）ごとの仲間キャラクター加入条件・スカウト要件（支援Lv、名声Lv、特殊条件、期限）を横断比較できる攻略用Webツールです。

## 主な機能
- **4主人公 横並び比較マトリクス表**: カイ篇、ディートリヒ篇、セオドラ篇、レダ篇の条件を一目で比較
- **スマホ最適化（ルート切替）**: 上部タブから見たい主人公だけを絞り込んでスマホ画面にフィット
- **加入済みチェック**: チェックを入れると行が薄くなり、ブラウザ（localStorage）に自動保存
- **検索 & フィルタ**: キャラ名、兵種、条件キーワード検索、未加入のみ表示
- **カスタム追加**: 自分で新キャラやメモを追加・編集・エクスポート可能
