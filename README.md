# FE万紫千紅 - 主人公別スカウト・加入条件まとめ

『ファイアーエムブレム 万紫千紅（Fortune's Weave）』における、各主人公（カイ、ディートリヒ、セオドラ、レダ）ごとの仲間キャラクター加入条件・スカウト要件（支援Lv、名声Lv、特殊条件、期限）を横断比較できる攻略用Webツールです。全58キャラクターを収録。

## 主な機能
- **4主人公 横並び比較マトリクス表**: カイ篇、ディートリヒ篇、セオドラ篇、レダ篇の条件を一目で比較
- **スマホ最適化（ルート切替）**: 上部タブから見たい主人公だけを絞り込んでスマホ画面にジャストフィット
- **ルート別個別加入チェック（グレーアウト）**: 各マスタップでそのルートだけ加入済（打ち消し線）に切替＆自動保存
- **条件抽出フィルター**: 名声Lv（Lv.2〜9など）や支援Lv、未加入のみでの抽出・絞り込み
- **ソート機能**: 支援順、名声順、期限順、名前順での昇順▲・降順▼並べ替え
- **キャラ条件の自由編集**: キャラ名をタップして条件をその場で書き換え保存可能
- **データのバックアップ・復元**: JSONファイルで保存・復元可能

## ファイル構成
- `index.html`: 画面のHTML骨組み
- `style.css`: デザイン・スタイルシート
- `data.js`: 全57キャラクターのマスターデータ
- `app.js`: ソート、抽出、保存などの動的ロジック
